DISASTER TAPE

Privacy policy

Last updated: 12 October 2026

Disaster Tape operates a private tool ("Disaster Tape Publisher") that connects to the YouTube Data API and YouTube Analytics API. It is used only by the owner of the Disaster Tape YouTube channel, to upload and manage that channel's own videos, thumbnails, captions, descriptions and comments, and to read that channel's own analytics.

What data the tool accesses

When the channel owner signs in with Google, the tool receives an OAuth token for the channel owner's account, with the YouTube scopes the owner approves. It reads and writes data belonging to the owner's own channel only. It does not access any other user's account, and it is not offered to the public.

How data is used and stored

Tokens are stored only on the channel owner's own computer, with file permissions restricted to the owner. They are used solely to perform actions the owner requests on the owner's channel. Data is not sold, shared with third parties, used for advertising, or used to train AI models.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services and is subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking access stops the tool from acting on the channel.

Viewers of the website and channel

This website does not use cookies, analytics or tracking. It is hosted on GitHub Pages; see GitHub's privacy statement for its server logging.

Contact

Questions about this policy can be sent through the contact details on the Disaster Tape YouTube channel.
